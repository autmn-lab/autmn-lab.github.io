About the Tool

As Cyber-Physical Systems (CPS) become increasingly autonomous, their underlying models grow more complex, combining nonlinear, stochastic, and neural-network-driven dynamics. Traditional formal verification methods such as model checking struggle to scale or generalize to such systems.

Runtime monitoring provides a practical and lightweight alternative: it verifies safety properties by analyzing the system’s generated or observed trajectories. However, existing monitoring techniques, especially those based on reachability, often fail when faced with the complexity of modern CPS or DNN-based components.

Posto introduces a statistical monitoring framework that combines simulation, uncertainty quantification, and probabilistic safety verification to deliver high-confidence safety guarantees for both analytical and learning-enabled CPS.

What is Posto?

Posto is a Python-based tool for probabilistic safety monitoring and verification. It enables the modeling, simulation, and verification of systems under uncertainty through three complementary modes:

  • Equation Mode: Uses mathematical models defined in .json files, specifying state variables, constants, equations, and safety constraints.
  • ANN Mode: Integrates trained neural network models (.h5 files) to emulate system behavior.
  • Dev Mode (Model.py): Lets users define their own dynamics in Python — ideal for testing new formulations, stochastic effects, or hybrid systems.

Core Functionality

At the center of Posto lies the System class, which drives the entire workflow:

Model Integration

Loads equation-based, ANN-based, or custom user models through a unified interface.

Behavior Generation

The behaviour() function generates and visualizes randomized trajectories from a given initial state set. By sampling multiple initial points and simulating their evolution across all state dimensions, Posto helps users intuitively explore the system’s dynamics, detect patterns, and identify regions of instability or convergence before verification begins. The resulting plots are automatically saved as high-resolution 2D and 3D visualizations.

Probabilistic Log Generation

The generateLog() command produces uncertainty-aware log files (.lg), which record the probabilistic evolution of the system’s state over time. Each log entry encodes a bounded interval for every state variable — representing uncertainty from noise, randomness, or parameter variation.

Safety Verification

The checkSafety() command evaluates trajectories and logs against user-defined constraints using the Jeffreys Bayes Factor (JBF) approach, providing statistical SAFE or UNSAFE classifications with confidence scores.

Visualization

Posto automatically generates interpretive plots that highlight safe versus unsafe regions, probabilistic log intervals, and trajectory evolution — offering both diagnostic and presentation-ready visuals.

Custom Model (Dev Mode)

Posto supports developer-defined models for advanced research use. Users can directly implement their own getNextState() function to describe the system’s dynamics, bypassing the need for equation or ANN files.
